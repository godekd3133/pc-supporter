단계 이동과 저장 견적

  • CPU 수동 순서는 가격 또는 영상 점수로 매번 재정렬하지 않습니다. 9800X3D → 9850X3D → 9900X3D → 9950X3D 순서를 유지합니다.
  • GPU 모델은 5060 → 5060 Ti → 5070 → 5070 Ti → 5080 → 5090으로 이동합니다. 5060 Ti 8GB/16GB는 같은 모델 단계입니다.
  • RAM 합계는 16 → 32 → 64 → 128GB, SSD는 500GB → 1TB → 2TB → 4TB로 이동합니다.
  • 쿨러는 기본 → 싱글 타워 → 듀얼 타워 → 3열 수랭 순서입니다. 파워·보드·케이스는 정한 용량 또는 물리 공간 조건을 확인합니다.
  • 저장 견적의 실제 용량과 비활성화 사유를 제한된 데이터로 유지합니다. 성능·호환성 판정은 서버에서 다시 확인합니다.
다음 단계가 없을 때

실제 판매 상품이 없거나 필수 조건을 충족하지 못하면 해당 방향을 비활성화하고 이유를 표시합니다. 다른 모델로 건너뛰거나 가짜 상품을 만들지 않습니다.

레퍼런스와 측정값

견본 조합은 추천이 따라야 할 기준입니다. 영상에서 확인한 게임 성능은 시험 조건에 해당하는 측정 자료입니다. 두 자료를 같은 의미로 사용하지 않습니다.

  • 이번 13개 조합은 사장님이 제공한 추천 레퍼런스입니다. 실제 모든 게임을 측정한 FPS 표가 아닙니다.
  • 기존 신성조 영상의 게임 성능 자료는 출처와 시험 GPU·메모리·해상도 조건을 유지합니다. 확인하지 못한 측정 행은 측정값으로 표시하지 않습니다.
  • 9800X3D부터 9950X3D까지의 동급 처리와 배틀그라운드 X3D 조건은 이번 프로젝트의 추천 정책입니다.
  • 매일의 가격 확인과 게임 성능 레퍼런스를 분리합니다. 가격만으로 CPU·GPU 밸런스를 다시 학습하거나 추측하지 않습니다.

QHD 12GB·4K 16GB는 사장님이 지정한 VRAM 기준입니다. 4K 예산 추천은 별도의 프로젝트 기준으로 RTX 5070 Ti 이상을 사용합니다. QHD RTX 5060 Ti 16GB도 허용하며, 실제 게임 FPS를 보장하는 기준은 아닙니다.
