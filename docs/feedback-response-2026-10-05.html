원본 PC Supporter API·작업 처리기의 쓰기를 멈춘 뒤 최종 백업을 만들고 복원했습니다. 재개 전 24개 테이블의 건수가 백업과 모두 일치했습니다. 상품 7,587개·액세서리 4,484개, 저장 견적·소유자 상태 0개를 확인했고 schema revision 3을 유지했습니다. 운영 파일과 기존 환경·관리 인증 비밀값도 함께 옮겼습니다.

실제 Azure 웹 화면 확인

새 세션에서 홈 → 새 PC → 예산 게임 → 80만원을 눌러 세 단일 선택이 즉시 다음 단계로 이동했습니다. 검토 화면의 ‘국내 신품 · 벌크 포함’을 확인한 뒤 5500GT · RAM 16GB · SSD 1TB · 500W · 759,640원을 생성했습니다. 성능 도움말 클릭과 예산·부품 − / + 표시를 확인했습니다. 내장 그래픽 게임 성능 18%는 지정 영상에 없는 추정값으로 설명하고, CPU 싱글 73.4%·멀티 45.7%와 구분합니다. 수정 전 CPU + 조절에서 5500GT → 5600G와 함께 불필요한 RTX 5050·600W 파워가 추가되고 336,650원 예산 초과가 표시됐습니다. 원인은 CPU 조절 입력이 외장 GPU를 강제로 포함하던 동작이었습니다. 이를 고친 릴리스에서 실제 CPU +를 다시 눌러 5600G · 내장 그래픽 · 500W · 786,730원을 확인했습니다. CPU만 바뀌고 GPU·파워·저장장치는 유지됩니다.

첫 화면 검사 중 API 재시작과 함께 CSS 미리 읽기 오류가 한 번 발생했습니다. 해당 CSS 파일이 서버에 있고 동일 파일이 HTTP 200으로 반환됨을 확인했으며 새로고침 뒤 정상 표시됐습니다. 파일을 수정해서 고친 것으로 기록하지 않습니다. 아래 세 장은 로컬 재현이 아닌 실제 Azure 화면입니다. 390 × 844px 모바일에서도 가로 넘침 없이 결과를 확인했습니다.
