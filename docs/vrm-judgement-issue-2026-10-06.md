# 메인보드 전원부(VRM) 판정 — 2026-10-06

`cpu-motherboard-power` 판정 방식을 정리한 기록입니다. 문제점, 이번에 바꾼 판정, 아직 정할 사항을 담았습니다.

## 바꾸기 전 문제 (엔진 2.62.0)

main 병합(`a3ece1f`) 뒤에는 두 정책이 섞여 있었습니다.

| 보드 데이터 | 판정 | 출처 |
| --- | --- | --- |
| 제조사 VRM 용량 표기 | CPU 전력이 초과하면 blocker | 공통 |
| Vcore 출력 합계 또는 Vcore 페이즈만 있음 | 공급 능력 추정(출력 × 0.35, 또는 페이즈 × 50A × 0.35). 초과 비율 1.1 미만은 info, 이상은 warning | feature/compatibility |
| 전원부 표기 없음 | CPU와 무관하게 일괄 warning | mkKim (`5161163`) |

**문제점**

1. **경고 등급이 섞였습니다.** "추정상 부족"과 "데이터 없음"이 같은 warning으로 나왔습니다.
2. **데이터 없는 보드에 경고가 남발됐습니다.** 65W급 CPU에도 warning이 붙었고, 문구는 "무리 없이 동작합니다"였습니다.
3. **추정 모델 근거가 약했습니다.**
   - 페이즈당 50A와 0.35 계수는 실측으로 보정되지 않았습니다.
   - 페이즈 수는 더블러·teamed 구성 같은 표기 관행에 따라 의미가 다릅니다.
   - 지속 공급 능력은 파워 스테이지 등급, 방열판, 에어플로우에 좌우되는데 반영되지 않았습니다.
4. **흔한 조합에서 오경보가 났습니다.** 코어 울트라 125W + B860M 7페이즈 보드가 "전원부 부족"으로 걸렸습니다(비율 1.02~1.19).
5. **인텔 K 모델을 과소평가했습니다.** PPT가 없으면 PBP 125W로 계산했는데, 실제 MTP는 159~250W입니다.

## 판단

- **증상의 성격:** 전원부 부족은 조립 불가가 아닙니다. 고부하가 오래 이어질 때 VRM 과열로 전력 제한이 걸리는 것으로 나타납니다. 그래서 blocker는 제조사가 밝힌 용량 같은 확정 근거가 있을 때만 냅니다.
- **mkKim의 원칙을 따름:** 검증되지 않은 계수로 W를 추정하지 않습니다.
- **feature 브랜치의 방향을 따름:** 일괄 경고 대신 실제 위험 조합만 골라냅니다.
- **보드 등급의 1순위 신호는 칩셋입니다.** 페이즈 수보다 칩셋 등급이 더 신뢰할 만합니다. 보급형 칩셋 보드에서는 제조사가 고전력 CPU의 전력 한도를 낮추는 경우가 많기 때문입니다.

## 변경 후 판정 (엔진 2.63.0)

| 조건 | 판정 |
| --- | --- |
| CPU 전력 정보 없음 | unknown |
| 제조사 VRM 용량 표기가 있고 CPU PPT(없으면 TDP)가 초과 | blocker. 기존 기준과 동일 |
| 제조사 VRM 용량 표기가 있고 초과하지 않음 | 표시 없음 |
| CPU 최대 전력 150W 이상 + 보급형 보드 | warning "보급형 메인보드에 고전력 CPU를 조합했습니다." |
| CPU 최대 전력 150W 이상 + 보드 등급을 알 수 없음 | info |
| 그 외 | 표시 없음 |

**CPU 최대 전력은 아래 순서로 정합니다.**
1. PPT
2. 인텔 MTP(다나와 `PBP-MTP: 125-250W`의 위쪽 값)
3. AMD는 TDP × 1.35(AMD의 PPT 정의)
4. 그 외에는 TDP

MTP는 전원부 판정에만 씁니다. 쿨러·파워 규칙은 기존처럼 PPT(없으면 TDP)를 씁니다.

**보급형 보드 기준**
- 칩셋이 A320·A520·A620·H310·H410·H510·H610·H810인 보드
- 또는 Vcore 출력 합계가 300A 이하인 보드

칩셋은 다나와 원문(`AMD B850`, `인텔 H610` 등)에서 읽고, 없으면 제품명에서 읽습니다. 페이즈 수(합계·Vcore 모두)는 판정에 쓰지 않습니다.

## 정할 사항

1. **고전력 기준 150W:** 코어 울트라5 245K/250K(MTP 159W)가 기준을 겨우 넘어 H610/H810에서 경고를 받습니다. 기준을 160W 이상으로 올릴지 정해야 합니다.
2. **보급형 칩셋 목록과 Vcore 출력 하한 300A:**
   - 하한은 실측 근거가 없는 임시값입니다.
   - B840처럼 목록에 없는 보급형 칩셋을 넣을지 정해야 합니다.
   - Vcore 300A는 B650M PG Lightning, B850M-X 같은 저가 B 칩셋 보드를 보급형으로 분류합니다.
3. **인텔 K + H810 조합의 등급:** H810 보드는 대개 인텔 기본 전력 한도로 동작합니다. 이 조합을 warning으로 둘지 info로 낮출지 정해야 합니다.
4. **보드 CPU 지원 목록(QVL):** 확보할 수 있으면 가장 확실한 blocker 근거입니다. 데이터 수집 경로가 필요합니다.
