# 견적 화면 문구·동작 점검 — 2026-10-05

## 바꾼 문구

견적 설정, 자동 구성, 최종 결과, 부품 설명, 저장·공유, 변경 이력과 텍스트 내보내기를 확인했다.

- ‘출처 조건 참고’ → ‘다른 PC에서 측정한 값’
- ‘상향/하향’ → ‘높이기/낮추기’, RAM·SSD·HDD는 ‘용량 늘리기/줄이기’
- ‘적정 구성/게임 역할’ → ‘필요 사양/권장 사양’과 실제 CPU 세대·GPU 모델·용량
- ‘조건 완화안/후보 조건/초안/알림 정책’과 내부 규칙 번호를 사용자 설명에서 정리
- 길게 나열하던 CPU·RAM·드라이버 차이는 ‘테스트 환경과 출처 보기’에 모음
- 프레임 안정성은 CPU 성능과 캐시로 예상한 등급이며, 1% low 실측값과 구분

사용자가 지정한 AMD 도움말, XMP/EXPO 같은 하드웨어 용어, 가격·호환·전력 조건의 의미는 유지했다.

## 고친 동작

1. 게임 견적의 RAM 32GB가 URL에서 생략되어 16GB로 돌아가던 생성 화면의 저장·복원 경로를 수정했다.
2. 조정 요청이 실패하기 전에 예산 입력이 바뀌던 처리를 성공 후로 옮겼다. 실패하면 기존 견적과 예산을 유지한다.
3. 최근 판매 중단 기록을 과거 상품 자료가 지우던 문제를 고쳤다. 가격 확인 시각과 판매 상태 확인 시각을 따로 비교한다.
4. 새 게임 견적 모드에서 비어 있던 SSD/HDD 조정 정보를 연결했다. 실제 용량을 바꾸고 HDD 개수는 유지한다. 연결 가능한 제품만 후보로 사용한다.
5. 내장 그래픽 구성에서 RAM 용량·같은 플랫폼의 보드 변경만으로 외장 GPU가 추가되지 않게 했다.
6. GPU 소비전력이 없어도 제조사 권장 650W와 선택 500W가 확인되면 전력 부족을 먼저 표시한다. 권장·선택 용량을 알고 있으면 누락된 정보로 표시하지 않는다.
7. 여러 RAM을 섞었을 때 첫 번째 제품의 규격·속도·타이밍을 전체 구성으로 판단하지 않게 했다.
8. FPS 테스트에 RAM 용량이 기록된 경우에만 그 용량을 맞춘 후보도 비교한다. 미기록 용량을 추정해 채우지 않는다.
9. 잘못된 게임·옵션·용도로 작성된 목표 FPS 견적 JSON이 적용되지 않도록 검사한다.
10. 내장 그래픽·제조사 정보 없음·호환 불가·가격 기록 없음·장착 치수 없음의 표시를 실제 상태와 맞췄다.

저장장치 용량 조정을 확인하기 위해 국내 신품 SATA SSD 500GB/2TB, HDD 2TB/4TB의 상품 페이지를 다시 읽었다. 이름과 상세 용량이 다른 상품 및 단종 상품은 제외했다. 가격은 임의로 낮추지 않았으며, 작은 용량이 더 비쌀 수도 있어 버튼에 가격 인하를 약속하지 않는다.
