# 1차 게임 견적 구현 및 검증 — 2026-10-05

현재 작업 폴더의 로컬 구현·검증 기록입니다. 참조 자료는 원문 조회 30종과 실제 수집한 공개 보조 레코드 3종이며, 개별 수집 시각을 보존했습니다. 커밋과 배포는 수행하지 않았습니다.

## 요청 범위

- 견적 설정의 단일 선택은 클릭 즉시 다음 단계로 진행합니다. 게임 1차 경로는 예산으로 진행하며, 입력이 여러 개인 작업·직접 사양 경로는 확인 단계를 유지합니다.
- CPU AMD 5000/7000/9000, 지정 보드 4종·RAM 3종·쿨러 4분류, RTX 50·지정 MSI RTX 3050 6GB·AFOX RX580 2048SP로 후보를 제한합니다. 국내 신품 가격과 정확한 상품 식별을 사용합니다.
- 80만원 외장 GPU 구성이 어려울 때 5500GT와 패키지 기본 쿨러를 구성합니다. 그 뒤 예산 안에서 GPU를 먼저 높이고, 필요한 CPU·전원·냉각·장착 조건과 요청 용량을 맞춥니다.
- 최종 견적 및 생성 결과에 게임 성능, 프레임 안정성, 싱글·멀티코어 지표와 원형 도움말을 제공합니다. 도움말은 호버·키보드·클릭/탭으로 열립니다.
- 예산은 10만원씩, 부품은 인접 후보로 조절합니다. CPU·보드·RAM 변경 시 플랫폼과 냉각·파워·케이스 조건을 함께 다시 계산합니다. GPU 변경 시 파워·케이스도 다시 맞춥니다.
- 5600 CPU 상향은 유효한 7500F 후보가 있으면 7500F를 우선하며, 실제 제품 ID를 사용하는 통합 회귀 검증을 포함합니다.
- RAM 하향에서 요청 용량을 맞추는 데 드는 실제 킷 수량까지 계산합니다. 더 비싼 RAM/플랫폼을 하향 후보로 제공하지 않습니다.
- 부품 직접 상향으로 예산을 넘으면 초과 금액을 표시합니다. 호환 불가 변경과 실패한 조정은 이전 견적을 보존합니다.
- 생성 견적 조절 문맥을 검증한 뒤 복원하므로 새로고침 후에도 최종 화면의 조절 버튼을 사용할 수 있습니다.
- 특정 게임 목표 FPS, 상세 최소·적정 티어 체계, NVIDIA/AMD 선택 토글은 요청의 후속 범위로 남겼습니다.

## 원인과 가격 계약

기존 일반 세대/브랜드 정책이 Ryzen 5000·7000 및 KLEVV를 제외했습니다. 가중합 순위는 CPU·RAM·주변 부품의 개선이 GPU 개선보다 유리해질 수 있었습니다. 1차 게임 경로는 별도의 지정 부품 및 GPU 우선 비교를 적용합니다.

실제 브라우저에서 생성 후 가격이 갱신되면 생성 당시 부품 행과 최종 호환 합계가 다른 시점을 가리키는 문제도 재현했습니다. 이제 서버가 호환 검사에 사용한 동일 카탈로그에서 `partPriceSnapshot`을 반환하고, 화면·구매 목록·견적 정보 복사는 그 단가에 수량을 적용합니다. 값이 미확인이면 숫자로 만들지 않으며, 저장 JSON의 크기·중복·가격·시각도 확인합니다.

## 성능 근거

- GPU: [지정 영상](https://youtu.be/iVL3KqqzlhM)의 QHD 평균 상대 성능을 사용합니다. RTX 5060 Ti **16GB**가 100%, 8GB는 97.4%입니다. RTX 3050 6GB와 RX580 2048SP도 원본 표의 별도 행으로 구분했습니다.
- CPU: [지정 영상](https://youtu.be/6NoegO2rlkE)의 Cinebench R23 상대 수치를 전사했습니다. 싱글 기준은 13600K, 멀티 기준은 14600K입니다. 9800X3D 싱글은 캡처 재대조 후 107.1%로 교정했습니다.
- 영상에서 직접 확인한 값은 `video_table`, 직접 확인하지 못한 모델과 내장 그래픽은 `model_estimate`로 구분합니다. 7400F·7500F의 영상 원본 수치는 아직 직접 확인하지 못했습니다. 추정은 동일 기준 CPU에 대해 정규화하며 영상 확인값으로 표시하지 않습니다.
- 프레임 안정성은 CPU 싱글코어·캐시의 추정 등급입니다. 5600 → 7500F → X3D 경로가 중간 → 높음 → 매우 높음으로 올라가는 회귀 검증을 포함합니다. 특정 게임 실측 FPS/1% low 검증과 구분합니다.

## 완료한 검증

- 전체 Vitest: **348개 파일 / 2,080개 테스트 통과**. 이후 RAM 하향 가격 보완을 포함한 엔진·1차 견적 **183개 회귀 테스트**도 통과했습니다.
- 참조 자료 경로 변경 후 1차 견적·카탈로그 20개 회귀 테스트도 통과했습니다. 테스트는 개인 data/catalog.json에 의존하지 않습니다.
- TypeScript 및 웹 production build, 클라이언트 번들 검증 통과. 마지막 CSS 변경도 `build:assets`로 빌드 및 번들 검증했습니다.
- 독립 코드/데이터 리뷰: 조정 의존성, 보드·쿨러·케이스 고정 경로, 영상 전사, 검사 가격과 복사 계약을 확인했습니다.
- 실제 API: 선택 수량에 검사 단가를 곱한 합계와 `coreTotalPriceWon`이 동일함을 assertion했습니다.
- 실제 브라우저: 단일 선택 자동 이동, 80만원 생성, 5500GT→5600 외장 GPU 추가, 5600→7500F의 보드·RAM 전환, 140만원의 RTX5060 Ti 8GB/16GB RAM/600W 구성, 최종 결과 전환, 도움말 표시·Escape 닫기, 예산 140→150→140, 새로고침 복원 확인.
- 390px 모바일 viewport: 가로 넘침 없음, 조절 버튼 및 지표 복원 확인. 실제 기기 설치/실행 검증은 수행하지 않았습니다.
