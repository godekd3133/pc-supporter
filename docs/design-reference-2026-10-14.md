# 레이아웃 참고: 노트북픽

- 확인일: 2026-10-14
- 출처: https://notebookpick.com/
- 사장님 요청: 디자인 레퍼런스로 확인. 후속 지시에서 레이아웃만 참고하도록 범위 확정.
- 확인: 공개 홈페이지 본문과 인앱 브라우저의 렌더링 화면.

## 참고할 구조

1. 상단에 로고와 간단한 탐색 메뉴 배치.
2. 짧은 소개 영역에서 서비스 목적 설명.
3. 추천 시작과 가이드를 별도 카드로 구분.
4. 추천 목록을 다음 영역에 배치하고 용도별로 구분.
5. 주요 버튼을 쉽게 찾도록 배치하고 영역 사이에 충분한 간격 확보.

## PC 서포터 적용 기준

- 위 정보 순서와 영역 구분을 레이아웃 참고로 사용.
- 색상, 글꼴, 로고, 문구, 카드 장식은 참고 범위에 포함하지 않음.
- 기존 PC 서포터 디자인과 견적 기능을 기준으로 세부 배치 결정.
- 이번 작업에서는 참고 범위만 문서화. UI 코드는 변경하지 않음.

## 확인 범위

- 홈페이지의 좁은 화면 배치와 본문 구조를 확인.
- 데스크톱 배치, 추천기 내부 흐름, 접근성은 검증하지 않음.
