## Browser review and runtime checks

- Reviewed the home, core catalog, accessory catalog, local-mode disclosure, and recommendation result in the actual built web output using a desktop browser at `http://127.0.0.1:4187/`.
- Home displayed the local-install banner and snapshot date. The core catalog route loaded the bundled catalog, displayed 379 CPU results on page 1 of 16, and showed product links with pcode-only URLs. No remote images are included; the interface uses category fallback artwork.
- The accessory page showed the full category totals in its selector. The page defaulted to `priceFilter=priced`, showing **4,474 / 4,484** accessories. The ten unpriced accessory records are present in the bundle but excluded by that default. The offline API accepts `priceFilter=all`, though the accessory UI's price menu exposes priced bands only.
- Core parts likewise default to known prices: **5,629 / 5,648** are priced and initially visible; 19 bundled items lack a price. Recommendation/catalog filters must not be read as evidence that the snapshot omitted those records.
- A gaming recommendation with a **₩2,000,000** budget and QHD 144 Hz target generated locally in under one second. It returned an estimated total of **₩1,973,930** and an `정보 부족` status. The selected board/CPU pair lacked motherboard VRM capacity data, so the compatibility result correctly reported that it could not establish CPU power-delivery headroom. The estimate included a 32 GB RAM kit at ₩674,970 and an RTX 2060 at ₩239,800; these are snapshot prices and the generated performance is not supported by FPS evidence. The visible disclosure states that benchmark/game FPS data is absent.
- Local drafts are stored in the current browser/device. The saved-history route states that server-saved quotes cannot be opened in this build. Cross-device saved builds, server sharing, live price refresh/history, benchmark/FPS filtering, administration, and data collection are unavailable in the static local build. Current price watch/quote state is local only and can be lost if the browser storage is cleared or evicted. The compatibility result still exposes a “견적 저장·공유” button and dialog offering “저장하고 링크 복사”; this conflicts with the local-mode disclosure, and the save submission was not attempted.
- The offline build's service worker uses revisioned shell/catalog caches. The browser review covered online loading and route rendering; it did not prove a cold first install or an offline reload after the Site has been published.
