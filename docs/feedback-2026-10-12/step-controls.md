# 부품 −/+ 단계 이동 — 2026-10-12

## 문제와 원인

기존 이동은 견적 후보 풀의 성능 점수를 정렬해 다음 후보를 선택했다. 후보 풀에서 중간 모델이 가격·호환 조건으로 제외되면 다른 모델로 건너뛰었다. GPU 5060 Ti의 8GB와 16GB 변형도 서로 다른 성능 점수여서 모델 변경으로 취급했다.

SSD와 HDD는 실제 존재하는 용량 중 가까운 후보를 찾았다. 2TB가 없으면 1TB에서 4TB로 이동할 수 있었다. RAM은 목표 용량과 정확히 일치하지 않아도 허용했고, 내릴 때 용량 오름차순으로 정렬해서 여러 단계를 내려갈 수 있었다.

## 수정 기준

- CPU: 수동 모델 순서를 명시했다. 추천용 게임 성능 점수와 독립적이다.
- AMD: 5500GT → 5600 → 7500F → 7600 → 9600 → 9600X → 9700X → 7500X3D → 7700X3D → 7800X3D → 9800X3D → 9850X3D → 9900X3D → 9950X3D.
- Intel: 12100F → 14100F → 13400F → 14400F → 14600KF → 250KF → 265K → 265KF. 지원 목록에 없는 플랫폼으로 임의 대체하지 않는다.
- NVIDIA: RTX 3050 → 5050 → 5060 → 5060 Ti → 5070 → 5070 Ti → 5080 → 5090. VRAM 변형은 같은 모델 단계다. 다음 모델에 현재 VRAM 용량의 상품이 있으면 우선한다. 해상도별 최소 VRAM은 엔진의 별도 조건이다.
- Radeon: RX 580 → 9060 → 9060 XT → 9070 → 9070 XT.
- RAM: 실제 합계 16 → 32 → 64 → 128GB. 목표 합계에 정확히 맞는 실제 키트 수와 보드 슬롯 조건을 검사한다.
- SSD: 500 → 1000 → 2000 → 4000GB. 512/1024GB는 각각 500/1000GB 단계에 포함한다. 허용 SSD 가족만 사용한다.
- HDD: 드라이브당 2 → 4 → 8 → 16TB. 드라이브 수는 유지한다.
- 쿨러: CPU에 포함된 기본 쿨러 → AG400 G2 → PA120 SE 서린 → NAUTILUS 360 RS. 기본 쿨러는 실제 CPU 패키지에 포함되고 전력 조건을 만족할 때만 허용한다.
- 보드: 같은 소켓 내 A520 → B550, B850 → X870E. CPU·RAM 플랫폼 변경은 CPU 수동 이동의 의존 부품 재구성에서 처리한다.
- 파워: 400/450/500/550/600/650/700/750/800/850/900/1000/1200/1300/1500/1600W 단계. 바로 다음 용량이 없거나 필수 전력·커넥터 조건을 만족하지 못하면 중지한다.
- 케이스: 가격이 아닌 GPU 장착 공간의 실제 카탈로그 순서. 물리 조건 필터를 적용하기 전에 다음 공간 단계를 정한다. 중간 공간 단계가 장착 조건을 만족하지 못하면 더 큰 케이스로 건너뛰지 않는다. 케이스 단계는 게임 성능 등급이 아니다.

## 없는 단계의 동작

바로 다음 단계에 판매 가능한 실제 상품이 없으면 ID를 생성하지 않는다. `upUnavailableReason` / `downUnavailableReason`에 이유를 제공한다. 가격 미확인 및 `priceUnavailableAt` 상품도 후보에서 제외한다. UI는 해당 방향을 비활성화하고 버튼의 마우스 설명과 접근성 설명에 그 이유를 표시한다. 호환성 검사는 엔진에서 추가 수행한다.

추천 계산의 가격·성능 shortlist를 수동 이동에 재사용하지 않고, 판매·명시 허용·필수 스펙 조건을 통과한 전체 후보를 별도로 사용한다. 현재 선택된 SKU도 풀에 포함한다. 메타데이터에 ID가 없이 사유만 있어도 응답에 포함한다.

클라이언트도 실제 용량을 확인할 수 있는 경우 RAM·SSD·HDD의 서버 전달 용량이 바로 이웃인지 검사한다. 저장할 때 `currentCapacityGb`에 메모리 합계 또는 드라이브당 실제 용량만 남긴다. 메모리는 1~1024GB 정수, 저장장치는 1~100000GB 정수로 제한하고 다른 부품 종류의 용량 필드는 거부한다. 비활성화 사유는 1~500자 문자열만 허용한다. 게임 성능·호환성·적정 등급 객체는 계속 제거한다. 실제 64GB/요청 16GB의 이전 견적도 64→32GB로 한 단계 내리고, 64→16GB 건너뛰기는 거부한다.
