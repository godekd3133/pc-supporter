# CPU·GPU 견본 기준 변경 — 2026-10-12

## 문제와 변경

이전 기준은 서로 다른 GPU에서 측정한 CPU 게임 점수를 GPU별 최소점수와 비교했습니다. 이 방식은 주어진 조합을 제대로 표현하지 못했고, 최신 CPU의 코어 수나 작은 점수 차이를 조합 등급에 반영했습니다.

`shared/gaming-build-references.ts`에 CPU 모델군별 GPU 조합을 명시했습니다. `cpuGpuBalanceFor`는 이 행렬에서 등급을 조회합니다. 부품 가격은 등급 계산에 쓰지 않습니다. 가격은 추천 후보의 플랫폼 비용과 예산 확인에만 사용합니다.

정책 버전은 `gaming-pairings-2026-10-12`입니다. 결과에는 기준 행 ID, 정책 버전, 배틀그라운드 등의 적용 조건을 보관합니다. 원 영상의 실측 게임 점수는 별도 자료로 유지하며, 파생 조합을 실측 결과로 표시하지 않습니다.

## 사장님이 지정한 조합

아래 등급은 CPU를 기준으로 표시합니다. GPU 등급은 반대 방향입니다.

| CPU | GPU | CPU 등급 |
|---|---|---|
| 14400F / 7500F | RTX 5050 | 좋음 |
| 14400F / 7500F | RTX 5060 | 살짝 약함 |
| 9600X | RTX 5060 | 좋음 |
| 7800X3D | RTX 5060 | 살짝 강함 |
| 7800X3D | RTX 5060 Ti / 5070 | 좋음 |
| 7800X3D | RTX 5070 Ti | 살짝 약함 |
| 7800X3D | RTX 5080 | 너무 약함 |
| 9800X3D 계열 | RTX 5060 Ti | 살짝 강함 |
| 9800X3D 계열 | RTX 5070 / 5090 | 좋음 |

9800X3D·9850X3D·9900X3D·9950X3D는 같은 밸런스 등급입니다. 원래의 게임 성능 측정값을 같은 값으로 덮어쓰지는 않습니다. 5060 Ti의 8GB·16GB 모델은 같은 CPU 밸런스 기준을 사용합니다.

사장님이 명시한 셀은 `director-pairing-reference`로 표시합니다. 나머지 조합의 보수적인 프로젝트 규칙은 `project-pairing-policy`로 구분합니다. RTX 40 시리즈와 Radeon 계열의 대응표도 프로젝트 규칙이며, 새 측정값으로 간주하지 않습니다. 알 수 없는 모델은 `undefined`를 반환하여 좋음으로 위장하지 않습니다.

## 게임·해상도 조건

- 배틀그라운드가 포함되면 non-X3D CPU는 최소 살짝 약함입니다. 원래 너무 약함인 조합은 유지합니다. 14900K도 이 규칙을 적용합니다.
- X3D도 GPU에 비해 너무 약하거나 강하면 경고를 유지합니다. X3D라는 이유만으로 모든 GPU와 좋음이 되지 않습니다.
- 해상도 VRAM 추천 기준은 FHD 8GB, QHD 12GB, 4K 16GB입니다. VRAM 조건은 CPU 밸런스와 별도입니다.
- 프로젝트 견본의 GPU 체급 하한은 4K RTX 5070 Ti입니다. QHD는 사용자가 지정한 VRAM 12GB 이상만 제한하며 RTX 5060 Ti 16GB도 허용합니다. 5060 Ti 16GB를 VRAM 용량만으로 4K 추천하지 않습니다. 이 하한은 프로젝트 추천 규칙이며 실측 FPS 보장이 아닙니다. FHD는 저예산 RX 580·3050을 위해 GPU 모델 하한을 강제하지 않습니다.
- 자동 추천은 CPU가 GPU 조합 기준을 충족해야 합니다. Intel을 직접 선택한 경우 기존과 같이 살짝 약함을 허용하되, 경고를 그대로 표시합니다.

## SSD

추천용 SSD는 500GB 이상으로 제한합니다. 요청한 용량 단계의 C910G를 우선 선택하고, 없으면 검증 모델 중 용량당 가격으로 정렬합니다. 자동 추천의 요청 용량은 최소값이며 최대 약 2배 용량까지 비교합니다. 더 큰 용량이 같거나 싼 가격이면 작은 SSD를 제외합니다. 수동 −/+ 용량 단계는 고정합니다. 500GB와 512GB, 1TB와 1024GB는 같은 단계입니다. 자동 추천에서 더 크고 싼 SSD를 용량 일치 때문에 제외하지 않습니다.

화이트리스트: KLEVV C910G, 삼성 970 EVO Plus·980·980 PRO·990 EVO·990 EVO Plus·990 PRO, SK하이닉스 P31·P41. 브랜드만 맞는 OEM/미확인 모델은 제외합니다. 해외구매·중고·판매불가 제외와 실제 M.2 슬롯 호환성은 기존 검증을 함께 사용합니다.

## 검증 범위와 남은 통합

회귀 테스트는 위 조합 13개, 상위 X3D 4개, Ti VRAM 동일 등급, 배틀그라운드, 알 수 없는 모델, 가격 독립성, SSD 최소 용량·모델·용량 단계 선택, 해상도별 GPU 체급을 포함합니다.

2026-10-12 targeted 검증: `npm test -- shared/cpu-gaming-policy.test.ts shared/gaming-build-references.test.ts`. 2개 파일, 26개 테스트 통과, 종료 코드 0. 로그는 [balance-reference-test.log](balance-reference-test.log)입니다. 첫 실행에서 SSD 테스트 생성 함수에 CPU 이름 접두가 남은 것을 확인하고 테스트 픽스처를 고친 뒤 전부 다시 실행했습니다.

엔진 통합을 완료했습니다. 생성 상태·최종 견적·편집기 분석에 `gamingGameIds`를 전달합니다. QHD·4K는 GPU 체급과 VRAM 하한을 함께 적용하며, 수동 GPU 고정에도 적용합니다. 해당 해상도는 내장 그래픽으로 대체하지 않습니다. 해상도를 지정하지 않은 1차 견적은 FHD로 처리합니다. FHD에서는 저예산 3050 6GB 선택을 유지합니다.

GPU를 수동 고정하고 CPU를 자동 선택할 때, CPU 예산 배분 35% 규칙이 꼭 필요한 X3D 후보를 제거하던 경로도 수정했습니다. 먼저 고정 GPU에 맞는 CPU 후보를 고르고 예산 배분을 적용합니다. CPU도 사용자가 고정한 5600·5090 구성은 물리 호환성이 있으면 유지하며 빨간 밸런스 경고를 표시합니다.

4K 예산 부족 오류에는 `resolution-budget` 진단을 추가합니다. 복구 선택지는 `resolution-edit-budget`, `resolution-fit-budget`, `resolution-recommended`입니다. 현재 카탈로그에서 실제 생성할 수 있고 가격이 완전하며 예산 안에 있는 후보만 제안합니다. 예산 수정 버튼의 동작은 UI에서 입력 변경만 수행합니다.

통합 회귀: 4개 파일·58개 테스트 통과. [balance-engine-test.log](balance-engine-test.log)에 기록했습니다. 수동 RAM의 플랫폼 전환 테스트는 DDR5 직접 선택으로 유지하고, Intel 14100F 다음 단계인 13400F가 없는 경우 건너뛰지 않는 기대값으로 갱신했습니다.

## 실제 카탈로그 확인

2026-10-12 운영 카탈로그 7,588개를 사용하는 로컬 엔진 2.62.0으로 검증했습니다. 이 검증은 부품 데이터와 엔진 결과이며 서버 배포 확인과는 별도입니다.

| 요청 | 결과 |
|---|---|
| 330만원 FHD, SSD 1TB | 7800X3D + RTX 5070, 2,606,940원, CPU·GPU 좋음 |
| 330만원 FHD + 배틀그라운드 | 동일 조합, 좋음 |
| 200만원 4K + 배틀그라운드 | 생성 거절, 추천 기준 최저 구성 3,365,150원 |
| 위 요청의 예산 수정 / 4K 추천 선택지 | 예산 3,540,000원, 실제 미리보기 3,365,150원 |
| 위 요청의 현재 예산 유지 선택지 | FHD, 1,989,560원 |

게임 목록은 세 선택지 모두 유지합니다. 330만원에서 더 높은 GPU 단계는 CPU·플랫폼을 포함한 조건이 예산을 넘기 때문에 남는 돈을 케이스·RAM 업그레이드에 쓰지 않았습니다. 증거는 `artifacts/feedback-2026-10-12/engine-reference-proof.json`, [실행 로그](engine-reference-proof.log)에 저장했습니다.

다음 GPU 단계도 별도로 점검했습니다. RTX 5070 Ti 16GB + 상위 X3D의 최소 구성은 3,365,150원으로 330만원보다 65,150원 높았습니다. 이 조합의 RAM은 32GB가 아니라 16GB 한 키트입니다. CPU 631,170원, GPU 1,799,000원, RAM 350,000원, SSD 287,980원 등 실제 카탈로그 단가를 합산했습니다. RAM 증설 때문에 GPU 단계를 놓친 경우는 아닙니다. 자동 SSD 500GB 이상 요청에서도 더 큰 1TB가 싼 경우 유지하도록 수정했으며, 수동 용량 단계의 정확한 이동은 별도 유지합니다.

추후 업그레이드 비용별 성능 변화 계산은 구현하지 않았습니다.

공개 응답에서도 4K 복구 버튼 3개가 유지되는지 검증했습니다. 내부 신호 비공개 처리에서 삭제되던 설명의 `FPS` 문구를 일반 성능 표현으로 바꾸고, `publicApiPayloadProjection`을 통과한 결과에 3개의 설명이 남는 회귀를 추가했습니다. 2차 게임 테스트는 기존 SATA SSD를 실제 제품인 것처럼 허용하지 않고, 같은 용량·가격 조건의 명시적 삼성 980 PRO 500GB·990 PRO 1TB/2TB M.2 NVMe 테스트 픽스처로 바꿨습니다. 내장 그래픽 테스트에는 FHD를 명시했습니다. AMD 판매자 선택 테스트의 120만원 한도는 새 CPU 밸런스·QHD VRAM 조건을 충족하지 못해 200만원으로 조정했으며, AMD 선택을 NVIDIA로 바꾸지 않는 원래 검증을 유지합니다.

최종 후속 회귀는 4개 파일·47개 테스트 모두 통과했습니다. [balance-phase2-integration-test.log](balance-phase2-integration-test.log)에 저장했습니다. QHD 측정 자료에서 RTX 5060 Ti 16GB의 69 FPS 기록을 사용하는 기존 경로도 통과했습니다. QHD의 12GB 조건과 실제 측정 자료를 유지하고 임의의 RTX 5070 모델 하한은 제거했습니다.
